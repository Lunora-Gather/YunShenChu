云深处 / The Deep Cloud

在 Mac 上解压整个文件夹，双击「打开云深处.command」。
启动器使用电脑上的 Python 3，在 Safari 中打开 http://127.0.0.1:4187/。
游玩时请保留启动窗口。第一次进入后，可以断网继续游玩。

下次双击同一个启动器，在 Safari 的标题画面点「继续调查」，即可回到待查街区或观察者案卷。五案都已结案时，会打开零号月台的发车清单。
「值夜巡查」单独接续你的班次。想从头玩一次，可在标题底部打开独立重玩档。

如果要发布到网站，把 site 文件夹内的所有文件放进网站目录。
换到其他地址或浏览器游玩时，会使用对应的独立存档。

值夜巡查
从标题画面或城区现场簿进入。任选两站取样，比较读数并调度机修组。四班过后可挑选轮值约定。进度随原档保存。

五案归档后再进值夜巡查，可以挑一封居民来信。第一班选承运人，下一班替居民接车或核验封缄。送成首趟后可请居民代抄读数。从同一居民的第三趟起，可选择带一件回程货去别的街区。退出后可从标题继续这封委托。
